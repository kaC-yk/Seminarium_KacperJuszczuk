## 📝 Opis Projektu

### Cel i motywacja
[Projekt powstał w celu umożliwieniu obywatelom niezrzeszonym komunikacje poprzez zintegrowaną aplikacje mobilną w przypadku sytuacji wyjątkowych związane z zagrożeniem życia czy tez innymi nagłymi przepadkami, projekt ma umożliwić użytkownikom wysyłanie między sobą alertów ogólnodostępnych dla każdego innego użytkownika. Aplikacja wtedy zbiera informacje o danym obszarze uszczególniąc ruch drogowy oraz zebrane informacje w celu dania innym u7żytkownikom odpowiednia informację do możliwości dokonania jak najbardziej trafnych decyzji dla ich bezpieczeństwa ]
